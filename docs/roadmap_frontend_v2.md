## 2. Принятые решения (отличия от исходной карты)

| Тема | Решение |
| --- | --- |
| Журнал | Таблица `progress_log(id, item_id, unit, number, logged_at)`, `unit` = `episode` / `chapter` / `movie`. Отдельной `watch_log` нет |
| Прогресс | Меняется только через `POST /items/{id}/progress` (`delta` = 1 или -1). `-1` уменьшает счётчик (не ниже 0) и удаляет последнюю запись журнала, если она есть, без ошибки при пустом журнале |
| Фильм | Прогресса в БД нет, завершённость только статусом. Переход в `completed` пишет в журнал `movie`/1, возврат из `completed` удаляет последнюю запись |
| Отзывы | Таблицы `reviews` нет. Одна личная заметка в `comment` (на фронтенде `note`) |
| Страницы книг | Не храним. Прогресс книг, манги и аудиокниг по главам (`current_chapter` / `total_chapters`), том отдельно (`current_volume`) |
| Категории | Все 8 есть в интерфейсе: `series` ↔ `tv_series`, `show` ↔ `tv_show`, остальные совпадают |
| Статус «просмотрено» | На фронтенде `done`, в БД `completed` |
| Дата завершения | `finished_at` ставит триггер БД при переходе в `completed`, сбрасывает при любом другом статусе. Через API только читается |
| Жанры | В БД и API строго нижний регистр, на фронтенде с заглавной. Заглушка «Без жанра» в БД не пишется |
| Общее число | `total_episodes` и `total_chapters`, `NULL` = неизвестно (на фронтенде `tot = 0`). У фильма не заполняется |
| Защита API | Если задан `API_KEY`, нужен заголовок `X-API-Key`. Открыты `/`, `/health` и `/posters/...` |
| Мост | Браузер ходит только в Next.js (`/api/backend/*`); сервер Next.js подставляет `X-API-Key`. Прокси пускает только разделы `items`, `genres`, `log`, `catalog`, `posters`, `health` и только с сессией. Постеры идут тем же путём |
| Данные | Источник правды БД. В localStorage только тема, язык, время копии и id «Продолжить» |
| Старт | Чистая БД, реальный список загружается `python -m scripts.import_json` |
| «Брошенный» тайтл | Отметка серии статус не меняет (и на сервере, и на клиенте) |

## 3. Текущий контракт

### Эндпоинты FastAPI

| Метод и путь | Что делает |
| --- | --- |
| `GET /`, `GET /health` | Приветствие и проверка БД (без ключа) |
| `GET /items/` | Список. Фильтры `category`, `status`, `genre`, `q`; `sort` (`updated_at`, `created_at`, `finished_at`, `title_ru`, `release_year`, `rating`), `order`, `limit` (1–500), `offset` |
| `GET /genres` | Жанры из БД, опционально `category` |
| `GET/PATCH/DELETE /items/{id}`, `POST /items/` | CRUD, PATCH частичный |
| `POST /items/{id}/progress` | `{"delta": 1}` или `{"delta": -1}`; ответ `item` и `entry`. Фильму 400, «уже всё отмечено» 409 |
| `GET /log` | Лента, свежие первыми: `limit` (1–100), `before` (id последней записи), `item_id` |
| `POST/DELETE /items/{id}/poster` | Свой постер (jpeg, png, webp до 5 МБ) |
| `GET /posters/{файл}` | Статика постеров (без ключа) |
| `GET /items/{id}/enrich/candidates`, `POST /items/{id}/enrich/apply` | Ручной выбор варианта обогащения, `force=true` заменяет только постер |
| `GET /catalog/search` | Живой поиск: `q` (от 2 символов), `category`, `limit`; ответ `results` и `errors` |
| `POST /items/from-catalog` | Создать запись из результата поиска (постер, жанры); дубликат 409 |

Ошибки внешних сервисов: 503 (не настроено) и 502 (недоступно или вернуло ошибку).

### Поля: интерфейс ↔ БД

| Интерфейс (`Title`) | БД (`media_items`) | Примечание |
| --- | --- | --- |
| `id` | `id` | Выдаёт БД |
| `type` | `category` | Таблица значений выше |
| `st` | `status` | `done` ↔ `completed` |
| `t`, `en` | `title_ru`, `title_original` | `""` ↔ `NULL` |
| `desc` | `description` | |
| `img` | `poster_url` | `/posters/42.jpg` ↔ `/api/backend/posters/42.jpg` |
| `y`, `c` | `release_year`, `country` | `0` и `"—"` ↔ `NULL` |
| `g` | `genres` | Регистр, см. решения |
| `se` | `current_season` | Пишется, если сезон больше 1 или просмотр начат |
| `ep`, `tot` | `current_episode`/`total_episodes` или `current_chapter`/`total_chapters` | Зависит от категории; `0` ↔ `NULL`; у фильма `ep` 0/1 по статусу |
| `vol`, `author`, `tr`, `link` | `current_volume`, `author`, `translation`, `source_link` | |
| `rate` | `rating` | `0` ↔ `NULL` |
| `note` | `comment` | |
| `h` | нет | Цвет заглушки считается из `id` |
| нет | `finished_at`, `created_at`, `updated_at`, `raw` | На фронтенде не используются |

Лента: `LogEntry` ↔ запись `progress_log` с названием тайтла (`unit`: `episode`→`ep`, `chapter`→`ch`, `movie`→`film`).

### 4.1. Долги этапов 2–4 — выполнено 2026-10-25

Сделаны пункты 1–5. Пункт 6 (живая проверка multipart) остаётся: проверить вручную при запущенных серверах. Неизвестная категория БД показывается как «сериал» (при сохранении такой записи через форму категория в БД сменится на `tv_series`).

Что именно:

1. **Пагинация до конца.** `api.listItems` берёт `?limit=500` один раз. Если записей больше 500, остальные не загрузятся и молча пропадут из интерфейса. Нужно читать страницами (`limit` + `offset`) до пустой страницы.
2. **Таймаут запроса.** В `call()` в `api.ts` нет таймаута: зависший сервер оставит интерфейс в ожидании. Нужен `AbortSignal.timeout` (например, 15 секунд, для загрузки постера больше) и русское сообщение «Сервер не ответил вовремя».
3. **Неизвестная категория.** `CATEGORY_FROM_API[...]` для неизвестного значения даёт `undefined`, и карточка ломает `unitOf` и подписи. Нужен безопасный запасной вариант и тест.
4. **Неизвестное «Всего».** Форма требует «Всего ≥ 1», хотя сервер и правила уже поддерживают `tot = 0` (идущий сериал). Разрешить пустое значение, показывать «серия N» без «/ всего».
5. **Мост (этап 2).** Явно писать `--host 127.0.0.1` в запуске FastAPI, убрать из `main.py` CORS (`allow_origins`), если фронтенд ходит только через прокси, добавить vitest-тест на то, что маршрут `/api/backend/*` без сессии недоступен.
6. **Проверка multipart.** Загрузку постера через прокси я проверял только юнит-тестами и вживую для JSON; загрузку файла вживую через Next.js нужно один раз прогнать.

```text
Закрой долги этапов 2–4 из docs/roadmap_frontend_v2.md, раздел 4.1:
1) api.listItems читает страницами по 200 до последней, без потолка в 500 записей;
2) call() в frontend/src/lib/api.ts получает таймаут через AbortSignal.timeout (15 с, для uploadPoster 60 с) и ошибку «Сервер не ответил вовремя» как ApiError со статусом 0;
3) toTitle и toCatalogResult не падают на неизвестной category: запись остаётся видимой (запасной тип), без падений в unitOf и подписях;
4) форма разрешает пустое «Всего» (tot = 0), интерфейс показывает прогресс без знаменателя;
5) в документации запуск FastAPI с --host 127.0.0.1, убрать лишний CORS из backend/main.py и обновить тесты, добавить vitest-тест на защиту /api/backend/* без сессии (логика проверки сессии из src/proxy.ts вынесена в чистую функцию, если нужно).
```

### 4.9. Прочие находки

- **Восстановление из файла копии.** Записи с неизвестным типом считаются ошибкой, уже существующие (то же название и тип) пропускаются; журнал просмотров из файла не восстанавливается, его ведёт сервер.
- **Старые данные в браузере.** Хранилище версии 3 при первом запуске сбрасывает старые `items` и `log` из localStorage (демо-данные). Если когда-то в браузере были реальные записи, перед обновлением сохраните их через «Сохранить базу данных» в настройках и загрузите кнопкой «Восстановить базу данных из файла».
- **Несколько вкладок.** Изменения из другой вкладки подтягиваются только после перезагрузки.
- **Офлайн.** Режима без сети нет: при недоступном сервере показывается плашка «Повторить».
- **Брошенный тайтл.** Отметка серии у него статус не меняет; если хотите возвращать в «смотрю», это правка в `backend/progress.py` и `rules.ts`.
- **Ключ TMDB.** Без `TMDB_API_KEY` поиск по сериалам и фильмам отвечает 503 (в общем поиске показывается как «Часть источников недоступна»).

## 5. Правила работы

- **Коммит после каждого этапа**, и только когда зелёные `pytest`, `typecheck`, `test` и `build`. Сейчас не сделан ни один коммит (раздел 4.0).
- **Новые зависимости** (SDK Anthropic на этапе 9, `openpyxl` на этапе 11) разрешайте явно, как в промптах.
- **Если этап слишком большой**, просите: «разбей на подзадачи и сделай только первую».
- **Что менять вместе:** изменение таблицы = `scripts/schema.sql` + `backend/models.py` + `backend/schemas.py` + тесты; новая строка интерфейса = `t("…")` и перевод в `src/lib/i18n-core.ts`; новая логика в `src/lib` = vitest-тест.
- **Внешние API в тестах не вызываются:** только заглушки и `tests/fixtures/`.
