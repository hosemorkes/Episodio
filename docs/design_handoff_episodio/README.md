# Handoff: Episodio — трекер сериалов, аниме, фильмов, книг и манги

## Overview
Episodio — mobile-first PWA-трекер контента. Пользователь ведёт библиотеку (аниме, сериалы, фильмы, книги, манга), отмечает серии одним нажатием, ставит оценки 1–10, пишет отзывы, листает каталог в стиле Netflix, смотрит анимированную статистику, общается с AI-компаньоном «Эпи», делает публичные витрины, экспортирует/восстанавливает базу. Интерфейс на русском и английском, две темы.

Целевой стек: **Next.js (App Router) + React + Tailwind CSS + Framer Motion**.

## About the Design Files
Файлы в этой папке — **дизайн-референсы, сделанные в HTML**: прототипы внешнего вида и поведения, а не продакшен-код. Задача: **воссоздать их в Next.js + Tailwind + Framer Motion**, используя принятые в кодовой базе паттерны. Копировать HTML напрямую не нужно. Прототип — это Design Component (`.dc.html`): шаблон с `{{ }}`-подстановками и класс `Component` с `state`/`renderVals()`. Вся логика и данные читаются из этих файлов.

## Fidelity
**Hi-fi.** Цвета, шрифты, отступы, анимации и тексты финальные. Воссоздавать пиксель-в-пиксель, подставляя токены в `tailwind.config`.

## Файлы
- `Episodio.dc.html` — всё приложение (все экраны, логика, словарь RU/EN, демо-данные). Главный референс.
- `Login.dc.html` — страница входа.
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — PWA.

- **Всего серий**: Geist 700 56px + «≈ N ч просмотра».
- **Эта неделя**: 7 столбиков (Пн–Вс), сегодня — акцентный цвет, остальные cyan 45%.
- **Мои тайтлы** — сетка карточек + кнопка «+ Добавить тайтл».
- **Последняя рецензия**.

**Карточка тайтла (TitleCard)**: aspect 3/4, radius 20, постер = загруженное изображение или градиент `linear-gradient(160deg, hsl(h1,55%,38%), hsl(h2,60%,22%))`. Левый верх: бейдж «★ оценка · тип». Правый верх: кнопка ✎ (44×44, blur). Низ: градиент к фону, название (Geist 600 15px), английское название (12px), мета «С1 · 61 / 87 · 2013», прогресс-бар 4px, круглая кнопка «+» 44×44 акцент. Hover: scale 1.03, тень `0 18px 40px rgba(0,0,0,.5)` + рамка акцент 40%. Нажатие на «+»: scale 1.25 пружина (`cubic-bezier(.3,1.6,.5,1)`, .18s), glow `0 0 28px акцент`, `navigator.vibrate(12)`, toast «Название · серия N». ### 3. Страница деталей (/title/[id]) — НЕ модалка
Полноэкранная страница (на мобильном критично). Верх: «← Назад», «✎ Редактировать». Постер (≤220px, 3:4, radius 20), название Geist 700 30px, английское, чипы (тип, год, страна, сезон, жанры), описание (15px, line-height 1.6). Блоки-карточки (radius 22, padding 20): **Статус** (pill 44px: Смотрю / В планах / Просмотрено / Брошено; «Просмотрено» ставит ep=tot, «В планах» — ep=0); **Ваш прогресс** (кнопки − и + 48px круглые, число Geist 700 44px, «/ total», прогресс-бар 8px, «Осталось серий: N»); **Ваша оценка** (кнопки 1–10 по 44×44, повторное нажатие снимает); **Отзывы** (список + поле + «Добавить отзыв»). Всё меняется на месте, без режима редактирования.
Для книг/манги — счётчики глав/страниц вместо серий (поля `pg`, `pgTot`; сейчас в прототипе подписи частично «серии» — довести).

### 4. Редактирование / новый тайтл (/title/[id]/edit, /title/new) — отдельная страница
Заменяет контент (на мобильном — полный экран, не оверлей). Кнопка «← Назад к просмотру» (для нового — «← Назад»). Поля: Тип (pill: Аниме/Сериал/Фильм/Книга/Манга), постер (Загрузить / Убрать, превью 72×104; хранить как dataURL → заменить на загрузку в storage), Название, Название (English), Описание, Сезон, Год выхода, Просмотрено серий, Всего серий, Страна, Личный рейтинг 1–10, Жанры (чипы-удаление, ввод + «Добавить», подсказки), «Удалить» (только для существующих). «Сохранить» — акцент, glow, min-width 140; по нажатию спиннер + «Сохраняю…» ~650 мс, затем возврат на страницу деталей с обновлёнными данными. Валидация: название обязательно, числа ≥0, ep ≤ tot, tot ≥1.

### 5. AI — чат с Эпи (/ai)
Контейнер max-width 820, высота `calc(100vh − 300px)`, min 460, radius 26. Шапка: аватар 42px (градиент акцент→cyan, буква «Э»), имя «Эпи», статус «Ваш компаньон в Episodio» / «печатает…». Лента: пузыри (user — справа, фон акцент, radius 18/18/6/18; агент — слева, фон card, 18/18/18/6), max-width min(580,88%), 15px, переносы строк, под ответом кнопки-действия (pill, рамка акцент). Индикатор набора — три точки (анимация opacity). Автопрокрутка вниз. Нижняя панель: быстрые вопросы (pill 40px: «Что вышло нового?», «Что можно досмотреть?», «Посоветуй что-нибудь», «Рецензия: серия топ, но концовка слита»), поле (48px) + «Отправить», Enter отправляет. Сейчас ответы правилами; в продакшене подключить LLM (Claude API) с контекстом библиотеки пользователя. Интенты: «что вышло» (выходящие тайтлы + анонсы, действие «В планы»), «досмотреть» (по близости к финалу, действие «Отметить»), «посоветуй» (по жанрам, действие «В планы»), «рецензия» (оценка, текст, теги). Задержка ответа ~900 мс.

### 6. Статистика (/stats)
Сетка 2 колонки (1 на <560). **При каждом открытии страницы** запускается анимация 1.8 c (easeOutCubic, старт через 150 мс; при уходе сбрасывается): **Жанры** — conic-gradient «собирается» по дуге, подписи появляются со сдвигом, проценты считаются от 0; **Страны** — полосы (8px, градиент акцент→cyan) заполняются; **Годы выхода** — столбики по корзинам (≤2009, 2010–14, 2015–19, 2020–22, 2023+) растут снизу по очереди; **Топ по сериям** — 5 строк выезжают по очереди, счётчик нарастает. Реализовать на Framer Motion (`whileInView`/ключ по pathname, stagger 0.07).

Сетка топ-4 карточек 3:4 с «#N», названием, «★ оценка / 10». Пусто → «Нет записей за этот период». «Поделиться» копирует ссылку. ## Interactions & Behavior (сводка)
- Все кнопки ≥44px; hover — смена рамки/подложки на акцент; focus полей — рамка акцент; active — scale.
- Анимации: pop (scale .6→1, opacity, .2–.3s), spin спиннера (.7s linear), переходы width/height баров .4–.5s, карточки .25s.
- Состояния загрузки: скелетоны вместо резких рывков (opacity 35–70% пульс, `@keyframes sk`) — предусмотреть для каталога и деталей.
- Переходы между страницами: Framer Motion `AnimatePresence` / View Transitions API.
- Горизонтальные ряды: скрытый скроллбар, `scroll-snap`.

## State Management
Модель `Title`: `{ id, type: 'anime'|'series'|'movie'|'book'|'manga', t, en, desc, img, y, c (страна), g: string[], se, ep, tot, pg, pgTot, st: 'watching'|'planned'|'done'|'dropped', rate: 0–10, rv: {a,t,r}[] }`. `CatalogItem`: `{ id, type, t, en, y, g[], c, r (рейтинг), p (популярность), s: 'o'|'d'|'s', tot }`. `LogEntry`: `{ day, title, ep, time }`.
Глобальный стор (Zustand): items, log, lastId (для «Продолжить»), theme, lang, user. Локально: фильтры каталога (cq, fGenres, fYear, fStatus, fSort, tfilter, catView), чат (messages, typing), форма редактирования.
Правила: `fixSt`: ep≥tot → done; done или planned с ep>0 → watching. `setStatus('done')` → ep=tot; `'planned'` → ep=0. Любое действие над тайтлом (отметка, статус, оценка, отзыв, сохранение) обновляет lastId.
Данные: сейчас в памяти; в проде — Postgres + REST/Server Actions; каталог — AniList (аниме/манга), TMDB (сериалы/фильмы), Open Library/Google Books (книги); импорт по ссылке (вставка URL → скелетон → заполненная карточка) ещё не реализован.

## i18n
Все строки в словаре RU→EN (`D` в `Episodio.dc.html`, ~250 ключей) + ответы Эпи на двух языках. Перенести в `next-intl`/JSON. Язык хранится в `localStorage['episodio-lang']`; в проде — в профиле. Данные пользователя (описания, отзывы) не переводятся.

## PWA
`manifest.webmanifest` (standalone, portrait, theme/background `#0F172A`, иконки 192/512/maskable, shortcut «Добавить тайтл» → `#add`), `sw.js` (stale-while-revalidate кэш, офлайн-фолбэк). В Next.js — `app/manifest.ts` + Serwist/next-pwa. Мета для iOS: apple-mobile-web-app-capable, status-bar black-translucent, apple-touch-icon. ## Известные пробелы прототипа
Нет реальной авторизации и БД; демо-каталог на 41 тайтл; Эпи — на правилах; нет импорта по ссылке (AniList/MAL/TMDB); публичные витрины без уникальных ссылок и привязки к реальным данным пользователя; счётчики глав/страниц для книг заведены в модели, но в UI подписи пока «серии»; нет скелетонов загрузки как отдельного состояния.

## Assets
Постеры — градиентные заглушки (изображений нет), загрузка своих — через редактор. Иконки приложения — сгенерированы. Иконок-библиотек нет (SVG-пути только у таб-бара; эмодзи не используются).
